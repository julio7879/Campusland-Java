### 👨‍💻 Sobre mí

Técnico en **Análisis y Desarrollo de Software (SENA)** con sólida formación en lógica **Backend**, modelado de bases de datos relacionales y calidad de software. Me especializo en construir aplicaciones robustas con **Java (Spring Boot), Python y MySQL**, apoyándome en herramientas de **Inteligencia Artificial y Protocolos Modernos (MCP)** para optimizar el análisis de requerimientos y la cobertura de pruebas.

- 🔭 **Proyectos recientes:** Arquitecturas web con Next.js/Supabase y microservicios backend con Java & Spring Boot.
- 🎯 **Enfoque profesional:** Prevención temprana de errores, diseño de casos de prueba funcionales y trazabilidad de requerimientos.
- 🤖 **Innovación con IA:** Empleo de agentes de IA y **Model Context Protocol (MCP)** para mantener sincronización estricta entre especificaciones técnicas, lógica de negocio y documentación.
- 📍 **Ubicación:** Cúcuta, Colombia 🇨🇴
